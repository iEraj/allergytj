# Privacy Policy

AllergyTJ does not collect, store, or transmit any personal information. There are no cookies, no user accounts, no analytics tracking, and no backend server.

The full privacy policy is available at **[allergy.tj/privacy](https://allergy.tj/privacy)**.

## Summary

- **No personal data collected.** No cookies, no sign-ups, no email addresses.
- **No backend.** The app runs entirely in the browser as a static site.
- **Local storage only.** Preferences (city, language, theme, notification settings) are saved on-device via localStorage and never transmitted.
- **Direct API calls.** Weather and air quality data is fetched by the browser directly from Open-Meteo and wttr.in. AllergyTJ never sees these requests.
- **GPS stays local.** If granted, location coordinates are used in the browser to find the nearest city. They are never sent to any AllergyTJ server.
- **Hosting.** The site is hosted on Vercel. Standard HTTP infrastructure applies. Vercel Speed Insights collects aggregate performance metrics without cookies or personal data.
