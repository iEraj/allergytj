Сиёсати махфият

Навсозии охирин: сентябри 2026

AllergyTJ вебсайти статикист, ки пурра дар браузери шумо кор мекунад. Ягон сервери бекенд, пойгоҳи додаҳо ё ҳисоби корбарӣ вуҷуд надорад. Ин саҳифа шарҳ медиҳад, ки ҳангоми истифодаи барнома бо маълумоти шумо чӣ рӯй медиҳад.

Чӣ ҷамъ мекунем

Ҳеҷ чиз. AllergyTJ ягон маълумоти шахсиро ҷамъ, нигоҳ ё интиқол намекунад. Ягон cookie, ягон бақайдгирӣ, ягон суроғаи почтаи электронӣ ва ягон пайгирии истифода вуҷуд надорад.

Захираи маҳаллӣ

Барнома якчанд танзимотро дар дастгоҳи шумо тавассути localStorage-и браузер нигоҳ медорад. Ин маълумот дар дастгоҳи шумо мемонад ва ба ягон ҷо фиристода намешавад:

  • Шаҳри интихобшуда
  • Забони интихобшуда
  • Мавзӯъ (равшан ё торик)
  • Танзимоти огоҳиҳо
  • Рад кардани пешниҳоди насб

Шумо метавонед ин маълумотро дар ҳар вақт тавассути танзимоти браузер пок кунед.

Маълумоти обу ҳаво ва сифати ҳаво

Ҳангоми истифодаи барнома, браузери шумо мустақиман ба ин хидматҳои тарафи сеюм пайваст мешавад:

  • Open-Meteo барои пешгӯии обу ҳаво
  • Open-Meteo Air Quality API барои маълумоти AQI (EU Copernicus CAMS)
  • wttr.in ҳамчун захираи обу ҳаво

Ин дархостҳо мустақиман аз браузери шумо ба он хидматҳо мераванд. AllergyTJ онҳоро ҳеҷ гоҳ миёнаравӣ, боздошт ё сабт намекунад. Ҳар як хидмат сиёсати махфияти худро дорад.

Ҷойгоҳи GPS

Агар тугмаи ҷойгоҳро пахш кунед, браузери шумо иҷозат мепурсад, ки координатҳоятонро мубодила кунед. Агар иҷозат диҳед, барнома аз рӯйхати собити 30 шаҳри Тоҷикистон наздиктаринро пайдо мекунад. Координатҳои шумо дар браузери шумо коркард мешаванд ва ба ягон сервери AllergyTJ фиристода намешаванд. Танҳо координатҳои наздиктарин шаҳр (на координатҳои шумо) барои гирифтани маълумоти обу ҳаво аз Open-Meteo истифода мешаванд.

Огоҳиҳои push

Огоҳиҳо дар браузери шумо дар асоси шароити ҷории гардолуд, AQI ва УФ тавлид мешаванд. Ягон сервери огоҳиҳои push вуҷуд надорад. Ҳамаи танзимоти огоҳиҳо дар localStorage-и дастгоҳи шумо нигоҳ дошта мешаванд. Ҳеҷ чиз кор намекунад, то ки шумо аниқ розигӣ надиҳед.

Корти мубодила

Функсияи мубодила тасвирро дар дастгоҳи шумо тавассути Canvas API эҷод мекунад. Агар онро мубодила кунед, ин тавассути механизми аслии мубодилаи дастгоҳи шумо ё ҳамчун зеркашии файл рӯй медиҳад. AllergyTJ тасвирро намебинад, нигоҳ намедорад ва интиқол намедиҳад.

Хостинг

Сайт дар Vercel ҷойгир аст. Мисли ҳар як хости веб, Vercel дархостҳои HTTP-ро коркард мекунад, ки суроғаи IP-и шуморо ҳамчун қисми инфрасохтори стандартии интернет дар бар мегиранд. AllergyTJ ба маълумоти инфиродии меҳмонон ё суроғаҳои IP дастрасӣ надорад. Vercel Speed Insights барои метрикаҳои умумии иҷроиш (Core Web Vitals) фаъол аст. Он cookie истифода намебарад ва маълумоти шахсӣ ҷамъ намекунад. Барои тафсилот сиёсати махфияти Vercel-ро бинед.

Service worker

Барнома service worker-ро барои кори офлайн ва кэшкунӣ насб мекунад. Он нусхаҳои файлҳои худи барномаро дар дастгоҳи шумо нигоҳ медорад, то ки барнома зудтар бор шавад ва бидуни интернет кор кунад. Service worker ҳеҷ чизро пайгирӣ намекунад.

Кӯдакон

AllergyTJ аз ягон кас, аз ҷумла кӯдакон, маълумоти шахсӣ ҷамъ намекунад.

Тағйирот

Агар ин сиёсат тағйир ёбад, мо онро дар ин ҷо бо сана навсозӣ мекунем. Азбаски барнома ҳеҷ чизро ҷамъ намекунад, тағйироти назарраси ин сиёсат кам эҳтимол аст.
